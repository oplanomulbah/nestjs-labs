# NestJS Labs 🧪

My personal repository for mastering NestJS, featuring structured exercises, architectural concepts, and production-ready mini-projects.

## 📁 Repository Blueprint

nestjs-labs/
├── .gitignore
├── README.md # Main index mapping out your learning journey
├── exercises/ # Short, hyper-focused coding drills
│ ├── 01-controllers-routing/
│ ├── 02-dependency-injection/
│ ├── 03-custom-pipes/
│ └── 04-guards-authentication/
├── projects/ # Full, standalone backend applications
│ ├── task-manager-api/
│ ├── ecommerce-microservice/
│ └── realtime-chat/
└── templates/ # Boilerplates to spin up new labs quickly
└── basic-rest-template/

### 🏋️ Exercises

- **01-controllers-routing**: Hands-on with routing decorators, payloads, and query parameters.
- **02-dependency-injection**: Understanding scopes (Transient, Request, Singleton).

### 🚀 Projects

- **task-manager-api**: A full REST API featuring PostgreSQL, TypeORM, and JWT Authentication.

## 🛠️ Global Prerequisites

- Node.js (v20+ recommended)
- NestJS CLI (`npm i -g @nestjs/cli`)
